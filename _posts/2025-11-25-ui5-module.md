### Modules  
* 재사용을 위해 index.js에 생성하여 사용한다.  
* 정의 시, sap.ui.define 구문을 활용한다.

&nbsp;  

**기본형**
  sap.ui.define([], function() {});  

&nbsp;  

### 예시  
모듈을 만들어본다. 화면에 버튼과 텍스트를 조회되게 한다.  

&nbsp;  

```javascript
sap.ui.define(["sap/m/Text", "sap/m/Button"], 
        function(Text, Button) {}); 
```
> sap/m/Text라는 컨트롤이 필요해. 얘를 Text라는 별칭으로 부를 거야.

&nbsp;   

```javascript
sap.ui.define(["sap/m/Text", "sap/m/Button"], function(Text, Button) {
    //Module에 대한 로직 구현
    //new sap.m.Text 라고 부를 필요 없어 이제. 이미 위에서 별칭을 줬으니까 걔로 하면 됨.
    var oText = new Text({
        text: "I'm Module Text"
    });

    oText.placeAt("content");
    // 이 모듈을 사용하면 -> index.html에서 body(id: content)에 위치시킴
});
```

&nbsp;   

> 이 모듈을 사용하기 위해 index.html에 가서 이 모듈 사용한다고 써야 한다.

&nbsp;  

```html
    <script id="sap-ui-bootstrap"
            src="resources/sap-ui-core.js"
            data-sap-ui-theme="sap_hcb"
            data-sap-ui-libs="sap.m"
            data-sap-ui-compatVersion="edge"
            data-sap-ui-async="true"
            data-sap-ui-resourceroots='{
                "com.sap.training33.sapui533": "./"
            }'
            data-sap-ui-onInit="module:com/sap/training33/sapui533/reuse" 
    ></script>
```  

* data-sap-ui-async="true”  
  : 비동기. cf. 동기→라이브러리 다 기동될 때까지 기다려야 해서 오래 걸린다.   
* data-sap-ui-resourceroots  
  : 이 프로그램의 루트를 잡아줘.  
    index.html이 있는 이 위치를, 현재 위치가 root(webapp라는 물리적인 폴더)인데,  
    "./" <- 앞으로 그 이름을 com.sap.training33으로 부르겠다.    
* data-sap-ui-onInit="module:sap/training/exc/index"  
  : 이 시점에 로딩하겠다.
