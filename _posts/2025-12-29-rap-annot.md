# Annotation이란?
> CDS 엔티티/뷰에 필드 의미와 UI·검색·서비스 동작 규칙을 메타데이터로 선언해, OData/Fiori/RAP 런타임이 자동으로 해석·적용하게 하는 표기  

=> 코드로 하드코딩하지 않고 @어노테이션으로 데이터의 속성 및 화면에서 어떻게 비출지를 설정한다.  

e.g.  
“이 필드는 금액이야/통화는 이거야”  
“이건 검색에 걸리게 해”  
“이 뷰는 UI에서 이렇게 보이게 해”  
“이 엔티티는 서비스에 노출할게”  
“이건 텍스트를 같이 보여줘”  

---

## Annotation은 어디에 적용하나?
> Metadata Extension > Projection View > Interface View 순으로 우선순위가 적용된다.

>  **Global Selection field**를 원한다면?  
> @Search.searchable: true → “이 뷰 전체에 글로벌 검색 기능 켜줘.”   
> @Search.defaultSearchElement: true → “글로벌 검색창에 입력한 텍스트를 이 필드 값과도 매칭해서 찾아줘.”
<img width="1895" height="353" alt="image" src="https://github.com/user-attachments/assets/7539c474-9627-46cc-94b3-5b7961b33e25" />

```abap
@Metadata.layer: #CORE
@Search.searchable: true
annotate entity ZC_TRAVEL_HR_MC
    with 
{   
    @UI.lineItem: [ { position : 10 } ]
    @Search.defaultSearchElement: true
    TravelId;
    @UI : { lineItem:       [ { position : 20 } ],
            selectionField: [ { position : 10 } ] }
    @Search.defaultSearchElement: true
    AgencyId;
    //AgencyName;
    @UI : { lineItem:       [ { position : 30 } ],
            selectionField: [ { position : 20 } ] }
    @Search.defaultSearchElement: true
    CustomerId;
    @UI.lineItem: [ { position : 40 } ]
    BeginDate;
    @UI.lineItem: [ { position : 50 } ]
    EndDate;
    @UI.lineItem: [ { position : 60 } ]
    TotalPrice;
    @UI : { lineItem:       [ { position : 70 } ],
            selectionField: [ { position : 30 } ] }
    @Search.defaultSearchElement: true
    OverallStatus;
}
```

### 2. objectModel.text ( 예외 : Projection View에 적용 )
> 코드와 description을 동시에 보여준다.
> 해당 annotation은 metadata에 적용을 못하기 때문에, Projection View에 적용한다.
<img width="1517" height="434" alt="image" src="https://github.com/user-attachments/assets/dee9f0e9-b486-4a3a-a9a4-7a81c9b97b83" />

구문: **@ObjectModel.text.element: [ '필드명' ]**

```abap
@AccessControl.authorizationCheck: #NOT_REQUIRED
@EndUserText.label: 'Travel Projection View'
@Metadata.allowExtensions: true
define root view entity ZC_TRAVEL_HR_M 
provider contract transactional_query
as projection on ZI_TRAVEL_HR_M
{
    key TravelId,
    @ObjectModel.text.element: [ 'AgencyName' ]
    AgencyId,
    _AGENCY.Name as AgencyName,
    @ObjectModel.text.element: [ 'CustomerName' ]
    CustomerId,
    _CUSTOMER.LastName as CustomerName,
    BeginDate,
    EndDate,
    BookingFee,
    TotalPrice,
    CurrencyCode,
    Description,
    @ObjectModel.text.element: [ 'OverallStatusText' ]
    OverallStatus,
    _STATUS._Text.Text as OverallStatusText : localized,
    LastChangedAt,
    /* Associations */
    _AGENCY,
    _BOOKING : redirected to composition child ZC_BOOKING_HR_MC,
    _CURRENCY,
    _CUSTOMER,
    _STATUS
}
```

### 4. IDENTIFICATION Facet
> 선택한 헤더 정보를 Object Page에 보여준다.  
> @UI.facet을 추가 후, 해당 박스에 보여줄 필드에 identification을 추가한다.
<img width="1518" height="406" alt="image" src="https://github.com/user-attachments/assets/fd726d78-2b24-4daa-a3e4-700256c21f72" />

구문:  
    @UI.facet: [ {   
        id: 'Travel',  
        purpose: #STANDARD,  
        position: 10,  
        label: 'Travel',  
        type: #IDENTIFICATION_REFERENCE  
    } ]  

identification: [ { position : 10 } ]  


```abap
@Metadata.layer: #CORE
@Search.searchable: true
annotate entity ZC_TRAVEL_HR_MC
    with 
{   
    @UI.facet: [ { 
        id: 'Travel',
        purpose: #STANDARD,
        position: 10,
        label: 'Travel',
        type: #IDENTIFICATION_REFERENCE
    } ]

    @UI : { lineItem:       [ { position : 10 } ],
            identification: [ { position : 10 } ] }
    @Search.defaultSearchElement: true
    TravelId;
"중략
}
```
